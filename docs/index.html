claude-mods

Auto-handoff for Claude Code

A long Claude session loses its thread the moment you clear it. Auto-handoff writes a handoff for you before that happens, so the next session picks up where you left off.

1

What it does

0:33

At a token threshold, the mod saves a /next handoff on its own, then tells you to clear and run /prime.

2

Set it up in about two minutes

0:43

You need Claude Code, Node 18 or newer, and a model with a one million token context window.

The steps from the video

  1. Clone the repo and copy the two skills:
terminal
$ git clone https://github.com/m2ai-portfolio/claude-mods ~/.claude/mods
$ cp -r ~/.claude/mods/skills/next ~/.claude/mods/skills/prime ~/.claude/skills/
  1. In ~/.claude/settings.json, point CLAUDE_CODE_PLUGIN_DIRS under env at the mod's folder, using the full path:
~/.claude/settings.json
"env": { "CLAUDE_CODE_PLUGIN_DIRS": "/home/you/.claude/mods/auto-handoff" }
  1. Start a new chat (mods load at session start) and type /auto-handoff. It reports the trigger point.
  2. To prove it now, run /auto-handoff now after your first reply. When the band says saved, you are set.
